# MOS — Política de fuentes y corroboración

## Principio
MOS no determina la verdad por el tamaño, ideología, popularidad o carácter institucional de una fuente.

La pregunta editorial es: **¿cómo sabemos esto?**

## Tipos de fuente

- `official`: fuente oficial/primaria para el ámbito que le corresponde.
- `territorial`: autoridad o actor territorial con conocimiento directo del lugar.
- `community`: organización, radio, líder o red comunitaria.
- `independent_media`: medio o periodista independiente.
- `investigator`: investigador/a independiente.
- `elected_official`: congresista, diputado, concejal u otro funcionario electo.
- `citizen_report`: reporte ciudadano.
- `social_signal`: señal encontrada en redes sociales.

## Regla de acreditación

Una fuente puede estar registrada o identificada sin que eso convierta automáticamente sus publicaciones futuras en hechos confirmados.

## Evidencia

MOS registra, cuando existe:

- documento oficial o documento público;
- fotografía;
- video;
- geolocalización;
- testimonio;
- conjunto de datos;
- observación directa;
- declaración verificable.

## Corroboración

- `NONE`: una afirmación sin corroboración independiente.
- `ONE_SOURCE`: una fuente identificada aporta el reporte.
- `TWO_SOURCES`: dos fuentes independientes coinciden.
- `MULTIPLE_INDEPENDENT_SOURCES`: múltiples fuentes independientes coinciden.

## Publicación

Una afirmación puede mostrarse como **pendiente de verificación** si es relevante para la emergencia, pero debe estar claramente etiquetada como tal.

Las alertas críticas deben priorizar evidencia primaria o corroboración suficiente para el tipo de afirmación.

## Política frente a medios

MOS no utiliza una lista negra de medios. Los medios comerciales, independientes, comunitarios y las fuentes políticas pueden aportar información, pero cada afirmación se evalúa por separado.

Una investigación independiente con documentos puede tener un valor probatorio mayor que una noticia breve. Una publicación viral sin evidencia puede tener valor únicamente como señal.

## Política frente a declaraciones políticas

Las declaraciones de congresistas o funcionarios se registran como declaraciones hasta que sus afirmaciones puedan corroborarse con documentos, fuentes territoriales, datos u otras evidencias.

## Regla de transparencia

Siempre que sea posible, el usuario debe poder llegar al material original y conocer:

**quién lo dijo → cuándo → dónde → qué evidencia existe → qué otras fuentes lo corroboran → cuál es el estado MOS.**
