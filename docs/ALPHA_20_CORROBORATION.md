# MOS Alpha-20 — Independent Corroboration

## Rule
Two matching reports are not automatically two independent pieces of evidence.

MOS distinguishes:
- `CONSISTENT`: distinct sources with no shared origin report the same value.
- `UNRESOLVED`: distinct sources report different values.
- `INDEPENDENCE_INSUFFICIENT`: same source or demonstrably shared origin.

## Why this matters
A wire story copied by five outlets must not count as five independent confirmations. Source identity and content origin must be tracked separately.

## Safety boundary
This engine only classifies relationships. It does not declare a claim true or publish it. Downstream evidence, freshness, risk and Safety Gate controls remain mandatory.
